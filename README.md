# Luis Rasgado Portfolio

Personal portfolio built with Next.js 16, React 19, and Tailwind CSS 4.

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Edit content

Site text lives in `src/data/resume.ts`. Wrap a phrase in `**double asterisks**` to highlight it.

Blog posts live in `src/data/posts.ts`. Each post opens in a dialog from its card, and its read time is calculated from its length.
